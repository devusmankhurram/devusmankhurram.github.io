# Usman Khurram — Portfolio

A responsive static portfolio built with semantic HTML, CSS, and lightweight vanilla JavaScript. It has no build step or third-party runtime dependencies.

## Run locally

From this directory, run `python3 -m http.server 8000` and open http://localhost:8000.

The sitemap and robots file assume deployment at the GitHub Pages root `https://devusmankhurram.github.io/`; update those URLs if the final deployment uses another origin.

## Included

- Single-page portfolio with experience, featured work, skills, architecture concept, education, and contact details
- Inline case-study sections for EOB Parser, SoloSuit, and QABA Board on the single-page portfolio
- EOB Parser screenshots in `images/eob/` (non-identifying screens only)
- Original CV PDF at `files/Usman-Khurram-CV.pdf`
- Responsive navigation, reduced-motion support, SEO metadata, robots, sitemap, and favicon
